# Launchlane support site

Static pages for Launchlane's App Store listing, served by GitHub Pages at https://ky4l3.github.io/launchlane-support/.

- `index.html`: Support page, FAQ and the support assistant (App Store Connect **Support URL**)
- `privacy.html`: Privacy Policy (App Store Connect **Privacy Policy URL**)
- `terms.html`: Terms of Use, which supplement Apple's Standard License Agreement

The source lives in the Launchlane app repo under `docs/appstore/`. Edit the markdown files there, regenerate these pages, then copy them here.
